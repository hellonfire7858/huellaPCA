# 🌍 HuellaTotal - Calculadora de Huella Ambiental

Calculadora interactiva de huella ambiental personalizada con datos de referencia para **Colombia 🇨🇴**. Mide el impacto en tres ejes fundamentales: **Plástico**, **Emisiones de Carbono (CO₂)** y **Huella Hídrica (Agua)**.

---

## ✨ Características

- 🧴 **Huella de Plástico**: Medición detallada por consumo de botellas, bolsas, envases de delivery, snacks y artículos de higiene.
- 💨 **Huella de Carbono**: Estimación de emisiones por transporte en carro, moto/transporte masivo, vuelos aéreos, consumo de carne roja y electricidad.
- 💧 **Huella Hídrica**: Cálculo de agua directa e indirecta (duchas, lavado de ropa, dieta con carne y hábitos de grifo/riego).
- 📊 **Visualización Interactiva**: Gráficos de barras, torta y radar ambiental con Recharts.
- 💡 **Recomendaciones de Alto Impacto**: Consejos prácticos con estimaciones de ahorro real.
- 📤 **Compartir Resultados**: Generación de reporte y resumen copiable al portapapeles.
- ⚡ **Ultra Rápido y Moderno**: Desarrollado con React 18 + Vite, diseño responsive con estética Dark Mode Glassmorphism.

## 🚀 Despliegue en Vercel

Este proyecto está 100% listo para desplegarse en **[Vercel](https://vercel.com/)**:

1. Conecta este repositorio en Vercel:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
2. ¡Listo! Vercel desplegará automáticamente la aplicación.

## 💻 Desarrollo Local

